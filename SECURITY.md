# Security Policy

## Reporting a Vulnerability

Please do not disclose suspected vulnerabilities through a public GitHub issue.

Send security reports privately to:

**contact@koantum.co**

Where possible, include:

- affected contract or component
- technical description
- reproduction steps
- proof of concept
- potential impact
- suggested remediation, if available

Never include private keys, seed phrases, recovery material, signing credentials, or other secrets in a report.

## Scope

This repository contains the public KOANTUM smart-contract source code and test suite.

Private signing material, credentials, internal infrastructure details, and non-public operational-security information are intentionally excluded.

## Official Verification

Before interacting with KOANTUM, verify official information through:

https://koantum.co

and the official Base explorer records.
